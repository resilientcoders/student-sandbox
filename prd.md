# PRD - Sprint 1

## Problem
We need to build an AI document assistant that answers user questions

## User
Primary user

## Functional Requirements
- Retrieval from document text
- RAG-style question answering
- Conversation state storage
- UI chat interface with the following color scheme: #fffdfa, #24201f, and #ed1b24
- Backend context handling
- Safety filters
- Testing
- Have suggested routes/payloads for the app

## Acceptance Criteria
Based on the question that the user asks, the UI chat interface interacts with the user and outputs an answer based on the document in simple terms

## Non-goals
Adaptable architecture for iframe or pop-up window
